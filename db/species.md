# 物种知识库 — 中国赶海常见渔获

> 用途：按地点预置物种的权威参考 + 落点无预置时按滩涂类型推断的依据。字段：名称 / 科属·别名 / 栖息滩涂 / 挖法·技巧 / 时令 / 吃法。方言别名对提升"懂行感"很重要。

## 按滩涂类型的主类推断表

| 滩涂类型 | 主类渔获 |
|----------|----------|
| 沙质 | 蛤蜊（花蛤）、蛏子、文蛤、沙鸡子 |
| 泥质 | 青蟹、跳跳鱼、泥螺、海泥鳅 |
| 礁石 | 海螺（香螺/辣螺）、牡蛎、螃蟹（石蟹）、海胆、紫菜/海苔 |
| 混合 | 以上综合，礁沙交界物种最丰富 |

## 常见物种详细卡

### 蛤蜊（花蛤）
- **定义**：帘蛤科双壳贝，贝壳三角卵圆，花纹多。
- **栖息**：沙质浅滩，低潮后沙面可见"呼吸孔"。
- **挖法**：用耙子或手往孔下挖 5-10cm；雨后最好挖。
- **别名**：北方"蚬子"多指另一亚种；本地人称"花蛤、蛤蜊、嘎啦"。
- **做法**：辣炒 / 清蒸 / 姜葱。

### 蛏子（竹蛏）
- **栖息**：沙泥底质，S 形通道挖洞。
- **挖法**：**盐罐法**——见洞撒盐，蛏子受盐水刺激自行上窜，徒手抓；或深挖。
- **别名**："蛏子、海蛏、竹蛏"；闽粤一带称"海蛏子"。
- **做法**：蒜蓉 / 葱油 / 煮汤。

### 海螺（香螺/辣螺）
- **栖息**：礁石缝隙、礁石底。
- **捡法**：退潮后礁石缝、潮池内捡；翻石找。
- **注意**：有的海螺腹足有毒，本地经验最重要，不认识的别乱碰。
- **别名**："香螺、辣螺、锥螺"因地区而异。
- **做法**：白灼 / 炒。

### 牡蛎（生蚝）
- **栖息**：礁石、桥墩附着。
- **撬法**：退潮露出的礁石上附生，用蚝刀/硬物撬开取肉。
- **别名**：北方"牡蛎、海蛎子"，闽粤"蚝、生蚝、海蛎"。
- **做法**：炭烤 / 蒜蓉 / 生食（肥蚝）。

### 青蟹（蟚螠）
- **栖息**：泥质滩涂、红树林边缘、河口。
- **抓法**：夜间或退潮后沿滩涂找洞，下虎口夹；戴厚手套防螯。
- **注意**：被螯夹很疼，勿手搏大蟹。
- **别名**："青蟹、蟚螠、红蟳"（福建/潮汕）。
- **做法**：清蒸 / 姜葱炒。

### 跳跳鱼（弹涂鱼）
- **栖息**：泥质滩涂、红树林。
- **抓法**：用网/套杆，弹涂鱼极敏捷，得靠工具和耐心。
- **别名**："跳跳鱼、弹涂鱼、花跳"。
- **做法**：酥炸 / 炖汤。

### 泥螺
- **栖息**：泥滩表层。
- **捡法**：退潮后泥面扫捞，洗净吐沙。
- **注意**：需充分吐沙、熟制，生食风险高。
- **做法**：醉泥螺（浙江名菜）/ 炒。

### 石蟹（很多地区统称"螃蟹"）
- **栖息**：礁石区、石块下。
- **抓法**：翻石，快速用钳或手抓背壳。
- **做法**：清蒸 / 香辣。

## 时令速查（供"正当时"提示）

| 月份 | 当令 |
|------|------|
| 3-5 | 虾、蛏子开季 |
| 5-8 | 蛤蜊、海螺丰富，牡蛎尚可 |
| 9-11 | 螃蟹（青蟹膏满）、海螺肥 |
| 12-2 | 牡蛎最肥（"吃牡蛎冬令"），蛏子欠佳 |

> 以上为通用经验，具体以当地实际为准。

## 免责
> 物种识别以现场为准，不认识的生物**一律不碰**，可能剧毒（如某些海蛇、芋螺、有毒海胆）。本表为经验参考，非权威生物图鉴。
