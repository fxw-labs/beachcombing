# 物种知识库 — 中国赶海常见渔获

> 用途：按地点预置物种的权威参考 + 落点无预置时按滩涂类型推断的依据。
> 字段：名称 / 科属·别名 / 栖息滩涂 / 挖法·技巧 / 时令 / 吃法。方言别名对提升"懂行感"很重要。

## 按滩涂类型的主类推断表

| 滩涂类型 | 主类渔获 | 代表性挖掘工具 |
|----------|----------|----------------|
| 沙质 | 蛤蜊（花蛤/文蛤/白蛤）、蛏子（竹蛏）、黄蚬子、沙虫、沙鸡子 | 赶海铁耙、铲子、盐罐、抽筒 |
| 泥质 | 泥螺、青蟹、跳跳鱼（弹涂鱼）、海肠、海泥鳅、招潮蟹 | 泥靴/踏板、抽筒、虎口钳、网兜 |
| 礁石 | 海螺（香螺/辣螺/苦螺）、牡蛎（海蛎子）、石蟹、海胆、鲍鱼、藤壶 | 撬刀、手套、手电筒、铁勾 |

## 常见物种详细卡

### 蛤蜊（花蛤 / 文蛤 / 白蛤）
- **定义**：帘蛤科双壳贝类，中国沿海最普遍的赶海收获。
- **栖息**：沙质或泥沙混合浅滩，退潮后沙面可见细小的"呼吸孔"或喷水小孔。
- **挖法**：用小铁耙在沙面下 5~10cm 浅翻，见孔必挖；雨后退潮沙质松软最好挖。
- **别名**：北方通称"蛤蜊、嘎啦"；南方多称"花蛤、花蚬、文蛤（贵妃蚌）"。
- **时令**：4月 ~ 10月肉质最饱满。
- **做法**：辣炒蛤蜊（青岛经典） / 葱姜爆炒 / 蛤蜊冬瓜汤 / 清蒸。

### 蛏子（竹蛏 / 缢蛏）
- **定义**：竹蛏科贝类，长管状，潜伏极深。
- **栖息**：沙泥底质，在滩涂表面留下典型的"8字孔"或扁圆形呼吸孔。
- **挖法**：**盐罐法**——将精盐或浓盐水对准呼吸孔撒入，蛏子受高盐刺激会迅速向上喷水并探出壳，此时迅速捏住抽出；泥滩可用专用不锈钢抽筒。
- **别名**："蛏子、海蛏、竹蛏、指甲蚌"；闽粤称"海蛏"。
- **时令**：春季（3~5月）最为肥美。
- **做法**：蒜蓉粉丝蒸 / 葱油淋 / 盐焗 / 蛏子豆腐汤。

### 海肠（单环刺螠）
- **定义**：螠虫动物门，体呈圆筒状，胶质丰厚，北方渤海、黄海特产。
- **栖息**：潮间带中低潮区的沙泥质深滩，洞穴呈 U 字形，孔口常有小泥圈。
- **挖法**：大潮退大潮时，顺着 U 形双孔，用专业抽筒或长铁锹快速深挖（常深达 30~50cm）。
- **别名**："海肠子、海肠"；胶东与辽东半岛名贵渔获。
- **时令**：早春与秋冬（11月~次年4月），大风浪过后或严寒大潮最易在浅滩斩获。
- **做法**：海肠捞饭（胶东招牌） / 韭菜炒海肠 / 烤海肠。

### 黄蚬子（青柳蛤）
- **定义**：马珂蛤科，壳坚厚呈黄色或黄褐色，辽宁丹东东港与黄海北部特产。
- **栖息**：水质清澈的浅海沙滩或泥沙滩。
- **挖法**：退潮至最低潮线附近，用多齿铁耙深耙沙层。
- **别名**："黄蚬、丹东黄蚬子"。
- **时令**：春季至初夏（4~6月）最鲜甜。
- **做法**：原汁炭烤 / 白灼 / 辣炒。

### 鸟贝（鸟蛤）
- **定义**：鸟蛤科，斧足肌肉发达肥大，形似鸟头，肉质脆嫩极鲜。
- **栖息**：黄渤海中下潮区细沙或泥沙滩。
- **挖法**：大潮期退至最远滩面，寻找大呼吸孔挖掘。
- **别名**："鸟蛤、鸟头贝"。
- **时令**：冬春季节（12月~4月）。
- **做法**：温水快速焯水凉拌 / 葱油鸟贝 / 涮火锅。

### 沙虫（光裸星虫 / 方格星虫）
- **定义**：星虫动物门，无节蠕虫状，华南（广西北海、广东湛江、海南）顶级鲜货。
- **栖息**：平坦清洁的沙质潮间带，表面有微小起伏的小沙包或小眼孔。
- **挖法**：专业沙铲顺着孔道角度快速斜铲，动作须极快，否则沙虫瞬间缩入深沙。
- **别名**："沙肠子、海肠子（华南俗称）、泥丁（同类可口革囊星虫）"。
- **时令**：夏秋季最为肥嫩。
- **做法**：沙虫刺身（极新鲜时） / 蒜蓉粉丝蒸 / 沙虫煮粥 / 晒干煲汤。

### 海螺（香螺 / 辣螺 / 苦螺 / 响螺）
- **定义**：腹足纲软体动物，种类繁多。
- **栖息**：礁石缝隙、岩石背阴面、潮池底部、碎石滩。
- **捡法**：退潮后沿礁石区仔细搜寻，翻开未干涸的大石头下方；夜赶打手电拾取。
- **注意**：部分未知芋螺可能有剧毒，不认识的鲜艳锥形螺切勿徒手抓取。
- **别名**："香螺、辣螺、苦螺、红螺、海窝窝"。
- **时令**：全年皆有，5~9月最为活跃。
- **做法**：酱爆海螺 / 白灼蘸辣根 / 盐水煮。

### 牡蛎（海蛎子 / 生蚝）
- **定义**：牡蛎科双壳贝，营固着生活。
- **栖息**：潮间带礁石、防波堤、桩柱表面密集成群。
- **撬法**：退潮时露出的礁石上，用专用蚝刀插入贝壳缝隙扭转撬开，取其嫩肉。
- **别名**：北方称"海蛎子、牡蛎"；南方称"生蚝、蚝仔、海蛎"。
- **时令**：冬春季（11月~次年3月）肥满如凝脂。
- **做法**：炭烤蒜蓉生蚝 / 闽南蚵仔煎 / 海蛎豆腐汤 / 生食。

### 青蟹（锯缘青蟹 / 红蟳）
- **定义**：梭子蟹科大型蟹类，两螯巨大，极具攻击性。
- **栖息**：泥质滩涂、红树林边缘、河口咸淡水交汇处的深洞中。
- **抓法**：沿泥滩寻找洞穴，使用铁钩或长火钳探洞抓取；**务必戴厚胶皮手套**防强力夹伤。
- **别名**："青蟹、红蟳、膏蟹、蟚螠（幼体/小蟹）"。
- **时令**：秋季（8~11月）母蟹黄满、公蟹肉厚。
- **做法**：清蒸红蟳 / 姜葱炒青蟹 / 糯米蒸青蟹。

### 石蟹与杂蟹（花盖蟹 / 兰花蟹 / 招潮蟹）
- **定义**：沿海潮间带常见各种中小螃蟹。
- **栖息**：礁石缝隙、石块底部、泥沙表层。
- **抓法**：翻开礁石快速按住背甲两侧，避开双螯；泥滩用网兜围捕。
- **时令**：夏秋季。
- **做法**：香辣蟹 / 酱腌小蟹 / 煮海鲜粥。

### 八爪鱼（短蛸 / 长蛸）
- **定义**：头足纲八腕目，智商高、善伪装。
- **栖息**：礁石缝、废弃海螺壳、泥沙洞穴、潮池。
- **抓法**：翻石搜寻；或将盐水/诱饵探入石缝逼其爬出。
- **别名**："八带、八带鱼、八爪鱼、巴爪"。
- **时令**：春季产卵期与秋冬季最肥。
- **做法**：大葱炒八带 / 白灼八带蘸三合油 / 辣炒。

### 皮皮虾（虾蛄 / 濑尿虾）
- **定义**：口足目虾蛄科，尾部带刺，击打力强。
- **栖息**：泥沙质浅滩中下潮区，洞穴深且呈多孔连通。
- **抓法**：退潮至极点时用专用抽筒抽洞，或在浅水潮沟用小抄网兜捕。
- **别名**："皮皮虾、爬虾、虾爬子、富贵虾、濑尿虾"。
- **时令**：春季（3~5月）带籽母虾极鲜。
- **做法**：椒盐皮皮虾 / 清蒸原味 / 生腌（潮汕风味）。

### 泥螺
- **定义**：阿地螺科，壳薄脆，体外被黏液包被。
- **栖息**：极软的泥质滩涂表层。
- **捡法**：退潮后在泥滩表面成片扫捞，带回需在淡盐水中静置吐沙。
- **别名**："泥螺、吐铁、泥蛳"。
- **时令**：清明前后（桃花泥螺）最嫩，中秋前后脂膏饱满。
- **做法**：醉泥螺（江南非遗名吃） / 葱爆泥螺。

### 跳跳鱼（弹涂鱼）
- **定义**：弹涂鱼科，能用胸鳍在泥滩爬行跳跃，离开水亦能呼吸。
- **栖息**：华东、华南泥质滩涂与红树林湿地。
- **抓法**：极度机敏，需用长竹竿专用绳套、陷阱泥筒或抄网。
- **别名**："弹涂鱼、跳跳鱼、花跳、泥猴"。
- **时令**：夏秋季。
- **做法**：椒盐跳跳鱼 / 豆腐炖跳跳鱼汤 / 熏烤干制。

## 赶海老饕安全与免责守则
> 1. **剧毒物种绝对禁碰**：如蓝环章鱼（带有剧毒蓝色圆环）、织纹螺（春夏季毒素极高）、海蛇、芋螺，见之远离。
> 2. **生态底线**：抓大放小，抱卵母蟹及幼贝主动放生；翻动石块后请随手翻回复原。
> 3. 本表为经验与烹饪参考，野外生物辨识请以专业官方指导为准。
