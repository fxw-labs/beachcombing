## 检索与分流规则

1. **用户给出明确地名/景点**（如"大连金石滩"、"青岛金沙滩"、"青岛红石崖"、"黄岛城市阳台"）：
   - 在本索引匹配对应省份文件；
   - 打开对应 `db/<province>.md` 提取预置的坐标、物种、基准点、到达指引与安全注意事项。
2. **用户给出沿海城市泛指**（如"这周六去青岛赶海"、"去大连赶海"）：
   - 列出该城市/省份的内置经典点供用户选择或直接推荐最合适的一处。
3. **未命中内置库（冷门野滩/偏僻海湾）**：
   - 调用 `bin/beachcomb.py geocode <地名>` 解析经纬度坐标；
   - 根据经纬度在 `species.md` 中按滩涂类型推断主产物种；
   - 自动推荐同省 1~2 个邻近内置经典点作为备选。
4. **内陆城市**（如"北京赶海"、"成都赶海"）：
   - 礼貌提示该城市无海岸线，并根据地理就近推荐最近的沿海点（如北京推荐天津东疆港/秦皇岛浅水湾）。

## 新增赶海点规范

新增省份/点位时：编辑或新建 `db/<province>.md`，严格遵循 `templates/point-entry.md` 格式；并在本索引表格中同步更新登记行。编辑完成后运行：
```bash
python3 scripts/validate_db.py
```
