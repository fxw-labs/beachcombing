# 安全与合规模板

> 这些是动态插入报告的片段。核心契约：**撤退时刻永远置顶，越严肃越好**。所有内容存在的意义是让用户安全回家。

## 撤退时刻（必发，置顶）

```
## ⚠️ 安全撤退时刻

**下一个高潮 <HH:MM> — 请在 <HH:MM> 前离开滩涂/礁石区。**
```

## 大潮红警（潮差 > 2.5m 时）

```
🔴 **大潮警报：潮差 <X.X>m，涨潮快、退得远。** 务必比平时提前撤离，警惕水位突涨把归路切断。
```

## 估测数据声明（农历骨架兜底时）

```
⚠️ 当前潮时基于农历天文骨架估算（±1 小时）。**请务必以当地潮汐 App 实测为准，切勿依赖本估算判断撤退。**
```

## 按滩涂类型的风险提示

| 滩涂类型 | 风险与提示 |
|----------|-----------|
| 泥质（滩涂/淤地） | 谨防**陷人**，远离软泥深坑；穿高筒防陷鞋，结伴互助 |
| 礁石 | **防滑防割**，礁石湿滑、牡蛎壳锋利；穿防滑鞋，留意浪花袭击 |
| 沙质 | 谨防**离岸暗流**，水面平静也可能有流，不可贸然下水 |
| 混合 | 综合以上；礁沙交界处最易滑倒受伤 |

## 合规提示（以当地官方为准）

```
⚠️ 请自行核实：当地是否休渔期、是否保护区/禁渔区、挖取是否需许可。本报告不构成法律建议。
```

## 通用安全封底（报告尾部恒加）

```
**出海赶海请务必：结伴同行 · 看官方潮汐表 · 涨潮前撤离 · 远离陌生滩涂。**
```
